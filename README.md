# Embeddable Widget Platform

A multi-tenant embeddable widget platform for collecting visitor
submissions and delivering them to customers.

## Status

🚧 In development

## Project

This project is being developed as part of the internship capstone.

## Planned Capabilities

- Multi-tenant widget management
- Embeddable JavaScript widget
- Dynamic widget fields
- Cross-origin submissions
- Submission validation
- Rate limiting and spam protection
- Geo-enrichment with fallback
- Asynchronous notifications
- Customer dashboard
- Submission analytics
